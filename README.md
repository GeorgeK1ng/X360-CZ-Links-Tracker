# Webshare seznam a stavy

Python 3.11+, bez externích knihoven. Výchozí složka: https://webshare.cz/#/folder/QFWv3mjitp/xbox360cz

## Spuštění na počítači

```bash
python tracker.py scan
python tracker.py status ALq856jjpu hotovo --note "Zkontrolováno"
```

Výstupy v `data/`:
- `inventory.csv`: seznam pro Excel, názvy, odkazy, velikosti, stav a poznámky.
- `links.txt`: odkazy na všechny aktuálně nalezené soubory.
- `inventory.json`: hlavní evidence, v níž se uchovávají ruční stavy.

Stavy: `nové`, `rozpracováno`, `hotovo`, `přeskočeno`, `problém`.
Sloupec `status` je tvoje ruční evidence. Automatická kontrola je v samostatných sloupcích `download_status`, `download_code`, `download_message` a `checked_at`.
Příkaz status bez --note zachová existující poznámku.
CSV je export: ruční změny v CSV se při další aktualizaci přepíšou. Pro trvalé změny použij příkaz status, GitHub Actions nebo uprav status/note v JSON.

## GitHub

1. Vytvoř repozitář, ideálně soukromý. Nahraj **obsah** tohoto adresáře do jeho kořene, včetně `.github/workflows/inventory.yml` (nikoli ZIP).
2. Otevři **Actions → Webshare seznam → Run workflow**. Prázdné ID spustí aktualizaci.
3. Pro změnu stavu spusť stejný workflow, vyplň ID ze seznamu, stav a poznámku. Prázdná poznámka v tomto formuláři původní poznámku smaže.
4. Výsledky najdeš v `data/` v repozitáři a jako stažitelný artifact běhu.

Workflow také aktualizuje seznam denně kolem 05:00 UTC (07:00 v ČR v létě, 06:00 v zimě); GitHub může běh zpozdit. Plán běží z výchozí větve. GitHub může plán v neaktivním veřejném repozitáři pozastavit.
Pokud push selže, zkontroluj oprávnění Actions k zápisu a ochranu výchozí větve. Workflow vyžaduje povolený zápis botem.

Skript projde stránkování i podsložky a sjednotí duplicity podle ID. Zmizelé položky ponechá s `present=false`; to znamená jen nenalezení při posledním průchodu, ne potvrzení smazání. Ruční stav i poznámka zůstanou zachovány. Při chybě načítání se evidence neaktualizuje. Seznam se může během průchodu změnit, API neposkytuje atomický snímek.

Jiná složka:
```bash
python tracker.py --data-dir jina-data scan --folder 'https://webshare.cz/#/folder/ID/nazev'
```

Skript načítá metadata přes https://webshare.cz/apidoc/ (`folder`) a volitelně žádá o download URL (`file_link`). Nestahuje obsah souborů. Soukromé složky nepodporuje. Odkazy jsou na stránky souborů, nikoliv dočasné přímé download URL.

## Automatická kontrola stažení (verze 2)

```bash
python tracker.py scan --check-downloads
python tracker.py check
python tracker.py check --id q0g5ZndnJ4
```

Kontrola pošle požadavek `file_link` s `download_type=file_download`: ověřuje, zda server vydá odkaz ke stažení, místo pouhé existence stránky. Neautomatizuje prohlížeč. Zachytí i chybu `FILE_LINK_FATAL_4` odpovídající dočasné nedostupnosti. Download URL se neukládá.

| download_status | Význam |
| --- | --- |
| odkaz_vydán | Server vydal download URL. Přenos ani integrita celého archivu nejsou ověřeny. |
| dočasně_nedostupný | Server zamítl stažení jako momentálně nedostupné. |
| nenalezen | Soubor nebyl nalezen. |
| vyžaduje_heslo | Server požaduje správné heslo. |
| limit_stahování | Omezení souběžných stažení / zařízení. |
| neveřejný | Server označil soubor jako neveřejný. |
| neověřeno | Jiná odpověď serveru, například požadavek přihlášení; viz kód a zpráva. |
| chyba_kontroly | Síťová / HTTP chyba nebo neplatné XML, nikoli důkaz vadného souboru. |

Čas kontroly je v UTC. Prázdné sloupce znamenají, že kontrola ještě neproběhla. Po obyčejném `scan` se zachová starý výsledek i jeho čas; pro čerstvou kontrolu použij `--check-downloads`. Chybějící položky se při hromadné kontrole přeskakují.

GitHub workflow kontroluje stažení při každé aktualizaci seznamu. Kontroly jsou postupné s prodlevou a mohou trvat desítky minut. Síťové chyby se vykážou u konkrétní položky a běh pokračuje. Opakovaný běh umožní znovu ověřit dočasné chyby.

Bez tokenu se ověřuje anonymní požadavek, takže výsledek se může lišit od přihlášeného VIP prohlížeče. Pokud máš vlastní platný session token WST, můžeš jej nastavit jako GitHub Actions secret `WEBSHARE_WST`, lokálně jako stejnojmennou proměnnou prostředí. Token nevkládej do kódu ani JSON; může vypršet. Přihlašovací údaje skript nevyžaduje ani neukládá. Token je předán pouze Webshare API.

Při aktualizaci existujícího repozitáře nahraď `tracker.py`, workflow a testy; vlastní adresář `data/` ponech, aby se zachovaly tvoje stavy.

## Přehled přímo na hlavní stránce repozitáře (verze 3)

README se po každém úspěšném běhu automaticky přegeneruje v označené sekci nahoře. Obsahuje počty výsledků kontrol, seznam položek k prověření a tabulku všech souborů s odkazy, ID, automatickým výsledkem, ručním stavem, poznámkou a časem kontroly. Stejný přehled je v souhrnu běhu Actions.

První úplná kontrola po nahrání: **Actions → Webshare seznam → Run workflow**, ID nechej prázdné. Pak už běží denně. Ruční změna stavu aktualizuje README bez nové kontroly stahování. Do automatické sekce README nepiš vlastní text, při dalším běhu se přepíše; zbytek README zůstává zachován.

Při přechodu z verze 2 nahraď `tracker.py`, `.github/workflows/inventory.yml` a testy. Svůj `data/` ponech. Nový přehled se doplní do tvého README automaticky při příštím běhu; není nutné README nahrazovat.
